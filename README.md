2.Inside you need to create a .bat with this code inside (if you don't know how to make a .bat just search up)

And you can Download that .bat here https://github.com/mrpolaroidfreshandclean/Talking-Tom-Gold-Run/blob/main/start.ba (you can see the code inside it)

python -c "import mimetypes; from http.server import SimpleHTTPRequestHandler, ThreadingHTTPServer; mimetypes.add_type('text/javascript', '.mjs'); 

ThreadingHTTPServer(('127.0.0.1', 8111), SimpleHTTPRequestHandler).serve_forever()"

Do you see that ThreadingHTTPServer(('127.0.0.1', 8111) ? that 8111 it's a port, if that 8111 is closed you will need to change to another number:

8080 3000 8000 8111 5500

And when you open that .bat a cmd window will show up (it's like a debug)
